## 当前关注方向

### Agent Runtime

探索 Agent 的调度、状态管理、任务执行与生命周期控制。

### Tool System

构建统一的工具调用层，降低工具接入与维护成本。

### Memory System

研究短期记忆、长期记忆、向量检索与上下文压缩机制。

### Local AI

探索本地模型部署与低资源环境下的 Agent 运行方案。
