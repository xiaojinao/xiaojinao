## 当前项目

### Cellium-Agent

模块化桌面 Agent 框架。

核心设计原则：

- High Cohesion
- Loose Coupling
- Provider Agnostic
- Runtime Self-Extension
- Observable Execution

目标是构建面向长期运行任务的 Agent Runtime。

聚焦于：

- Agent Runtime
- Tool System
- Memory System
- Vision System
- Context Management
- Desktop Automation
